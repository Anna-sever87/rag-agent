# rag-agent

Учебный проект: RAG-агент на Python. Он хранит знания в векторной базе Pinecone, умеет читать страницы по ссылке и делает реальные запросы к открытому API.

## Что умеет агент

1. **Подключение к Pinecone.** Класс `RAGAgent` подключается к индексу (если индекса нет, создаёт его) и ищет в нём ответы по смыслу.
2. **Чтение страницы по ссылке.** Функция `add_url` скачивает страницу, достаёт текст, делит его на чанки (по 800 символов с нахлёстом 100), превращает каждый чанк в эмбеддинг и сохраняет в Pinecone.
3. **Запрос к внешнему API.** Инструмент `get_random_cat_fact` делает настоящий GET-запрос к `https://catfact.ninja/fact`. Если он недоступен, пробует запасной API `https://meowfacts.herokuapp.com/`.

## Как это работает

| Часть | Что используется |
| --- | --- |
| Эмбеддинги | OpenAI `text-embedding-3-small` (1536 измерений) |
| Векторная база | Pinecone, индекс `rag-agent`, метрика cosine |
| Модель | `gpt-4o-mini` |
| Агент | LangChain `create_agent` с тремя инструментами и памятью `InMemorySaver` |
| Парсинг страниц | `requests` и `BeautifulSoup` |

Инструменты агента:

- `search_knowledge_base` ищет ответ в векторной базе;
- `add_url_to_knowledge_base` читает страницу и добавляет её в базу;
- `get_random_cat_fact` берёт случайный факт о котах из открытого API.

## Установка и запуск

```
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и впишите свои ключи:

```
OPENAI_API_KEY=your_openai_api_key_here
PINECONE_API_KEY=your_pinecone_api_key_here
PINECONE_INDEX_NAME=rag-agent
```

Запуск тестовой проверки:

```
python rag_agent.py
```

Скрипт проверяет три вещи: подключение к Pinecone, добавление страницы по ссылке и работу агента с API.

```

Создаю индекс rag-agent ...
Индекс: rag-agent, векторов в базе: 0

=== Тест 2: чтение страницы по ссылке ===
Страница прочитана: 63533 символов, чанков: 60
Сохранено в Pinecone чанков: 60
Векторов в базе теперь: 60

=== Тест 3: вопросы агенту ===
Вопрос: Что на сохранённой странице сказано о форме Земли?
Ответ: Форма Земли близка к сплюснутому эллипсоиду, известному как геоид. Расхождение геоида с аппроксимирующим его эллипсоидом достигает 100 метров. Экваториальный диаметр Земли на 43 км больше полярного из-за экваториальной выпуклости, вызванной вращением планеты. Средний диаметр Земли составляет около 12,742 км.
[API] GET https://catfact.ninja/fact -> 200

Вопрос: Расскажи случайный факт о котах.
Ответ: У котов есть 32 мышцы, которые контролируют внешнее ухо (в отличие от 6 мышц у человека). Кот может вращать свои уши независимо на 180 градусов и поворачивать в сторону звука в 10 раз быстрее, чем лучшие сторожевые собаки.
```

Что показывает пример:

- в первом тесте найдено 0 совпадений, потому что индекс только что создан и пуст: проверялось подключение, а не качество поиска;
- страница разбита на чанки, и агент ответил по найденному тексту;
- API-инструмент сделал настоящий запрос, код ответа 200.

## Ограничения

- С одной страницы сохраняются первые 60 чанков (около 48 000 символов).
- Для проверки в `rag_agent.py` используется страница Википедии «Земля». Свою ссылку можно передать в `add_url`.
- Память агента (`InMemorySaver`) хранится только пока работает программа.
